# Тестовое задание в Eto legko (AD Robot)

## Задание

Написать скрипт-замерятель скорости интернета со своего компьютера.

Он должен принимать адрес, куда стучаться (какая-нибудь тяжелая картинка) , запускать последовательно 10 запросов к этому адресу, дожидаться ответа, вычислять среднее время запроса, объем скачанных данных и печатать в консоли скорость мб/с.

Ответ залить на github и дать репозиторий с инструкциями.

## Решение

Скрипт написан на Python 3.12+. Запросы выполняются через стандартную библиотеку, из сторонних пакетов используется только [truststore](https://pypi.org/project/truststore/) для проверки SSL-сертификатов.

Как работает:

1. Принимает адрес файла (например, тяжёлой картинки).
2. Последовательно выполняет 10 запросов. Каждый следующий запрос начинается только после того, как ответ на предыдущий скачан полностью.
3. Для каждого запроса измеряет время от отправки до получения последнего байта и объём скачанных данных.
4. Выводит среднее время запроса, общий объём скачанного и скорость в МБ/с (в скобках та же скорость в Мбит/с).

Скорость считается как `общий объём / суммарное время всех успешных запросов`. 1 МБ = 1 000 000 байт.

SSL-сертификаты проверяются через системное хранилище ОС, как в браузере. Поэтому работают и сайты, которые не отдают промежуточный сертификат, и корпоративные или антивирусные корневые сертификаты.

## Установка

Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/):

```bash
git clone https://github.com/woozlic/speed_test.git
cd speed_test
uv sync
```

## Запуск

```bash
uv run speed-test "https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg"
```

Без uv, через обычный Python 3.12+:

```bash
pip install .
speed-test "https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg"
```

Адрес нужно брать в кавычки. Если в нём есть `&`, `?` или другие спецсимволы, без кавычек командная строка (bash, PowerShell, cmd) обрежет адрес или выдаст ошибку:

```bash
uv run speed-test "https://speed.cloudflare.com/__down?bytes=25000000&r=1"
```

### Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| `url` | адрес файла для скачивания (`http://` или `https://`) | обязательный |
| `-n`, `--count` | количество запросов | `10` |
| `-t`, `--timeout` | таймаут ожидания данных от сервера, секунды. Ограничивает паузу при соединении и между порциями данных, а не всю загрузку: медленное скачивание большого файла может идти дольше | `30` |
| `-k`, `--insecure` | не проверять SSL-сертификат сервера (например, самоподписанный) | выключено |

## Пример вывода

```
Адрес: https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
Запросов: 10

Запрос  1/10: 14.68 МБ за 2.077 с
Запрос  2/10: 14.68 МБ за 2.148 с
...
Запрос 10/10: 14.68 МБ за 2.103 с

Успешных запросов:    10/10
Среднее время:        2.112 с
Скачано всего:        146.80 МБ
Скорость:             6.95 МБ/с (55.59 Мбит/с)
```

Если запрос завершился ошибкой (сеть недоступна, HTTP 404 и т. п.), скрипт сообщает об этом и продолжает со следующего запроса. Итог считается по успешным запросам.

Замер можно прервать клавишами `Ctrl+C`. Скрипт выведет «Прервано.» и итог по уже завершённым запросам.

Код завершения: `0`, если успешен хотя бы один запрос; `1`, если не удался ни один; `2` при неверных аргументах; `130` при прерывании через `Ctrl+C`.

## Тесты
